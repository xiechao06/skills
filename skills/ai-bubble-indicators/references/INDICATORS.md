# 三组指标定义与阈值

框架来源：AI 资本周期「分层塌方」监控（融资结构先破，而非技术本身）。

## 系统规则

| 条件 | 含义 |
|------|------|
| 仅 1 组 red/yellow | 局部压力 |
| 2 组 red | 高压预警，尚未宣称系统性崩盘 |
| **3 组同时 red** | **系统性去杠杆信号** |
| 形态 | 分层塌方（尾部/弱商业化先死），非必然一日巨响 |
| 节奏参考 | 尾部压力常在 4–8 个季度内显性化（启发式，非日程表） |

## Group 1 — 资本覆盖（Capital Coverage）

### RCR（Revenue Coverage Ratio）

**问题：** 这堆 AI 资产赚的钱，够不够养活自己？

```
RCR = 合格 AI 毛利 / 年化资本负担
```

**分子（合格 AI 毛利）**

```
外部客户真实 AI 相关收入 × 毛利率
```

剔除：

1. 巨头投资模型公司后回流的云/GPU 采购（左手倒右手）
2. 内部业务转移计价（纸面用量）

**分母（年化资本负担）**

启发式（与房贷类比）：

- 本金 = 新增 AI 相关设备/机房资本开支
- 资本成本 ≈ 10%（含权益成本、摩擦，不单是债息）
- 经济寿命 ≈ 3–6 年（偏保守可用 4–5；会计常用 ~6）
- 粗算：每 $100 capex → 每年固定成本约 $20–$30

**解读**

| RCR | 含义 |
|-----|------|
| ≥ 1.0 | 毛利可覆盖年贡（健康方向） |
| 0.7–1.0 | 勉强，缓冲薄 |
| 0.5–0.7 | 黄色：依赖融资/存量现金 |
| < 0.5 且 capex 仍高增 | 红色：靠融资硬撑扩张 |

**辅助字段**

- Hyperscaler 合计 capex（MSFT/AMZN/GOOGL/META，可加 ORCL）
- AI 相关 capex 占比（若披露）
- 头部模型公司收入/ARR 与亏损
- 自由现金流（FCF）趋势

## Group 2 — 需求转化（Demand Conversion）

**问题：** 企业买了 AI 之后，到底用不用、续不续、赚不赚钱？

### 2.1 试点 → 生产转化率

```
转化率 = 全组织/生产环境部署数 ÷ 试点项目数
```

| 水平 | 状态 |
|------|------|
| ≥ 25% | 可接受（视行业） |
| < 25% | 黄色危险线 |
| < 15% | 红色（大量烂尾） |

### 2.2 净收入留存 NRR

```
NRR = 同期老客户本期经常性收入 ÷ 上期经常性收入
```

| 水平 | 状态 |
|------|------|
| ≥ 110% | 健康扩张（传统优质 SaaS 常 115–130%） |
| 100–110% | 持平略增 |
| < 100% | 黄色：净流失 |
| < 80% 或长期 20–40% | 红色：尝鲜后卸载 |

注意：嵌入式 copilot、云绑定产品与独立 wrapper 的 NRR 不可混谈。

### 2.3 用量 vs 毛利率剪刀差

- 调用量/token/ARR 上行，但毛利率下行 **>3pct** → 黄  
- 下行 **>5pct** 且与用量明显背离 → 红（规模变成亏损加速器）

### 2.4 企业 ROI 调研（软指标）

BCG / McKinsey / IBM CEO / 投行对标普成分股「可衡量 AI 收益」占比，作旁证，不单独定红灯。

## Group 3 — 融资压力（Financing Pressure）

**问题：** 还有没有人愿意为这套叙事继续掏钱？

### 3.1 一级市场难看融资

| 指标 | 黄 | 红 |
|------|----|----|
| Down round 占比 | >20% | >30% |
| Bridge / 扩展轮（A++ 等）占比 | >35% | >50% |

**人才/团队收购（acqui-hire）**：常为隐晦降价退出 + 规避部分并购摩擦。统计 down round 时应考虑是否并入「广义压力」。

### 3.2 老股/二级份额折价

```
折价 = 1 − (转让成交价 ÷ 最近轮融资估值)
```

| 折价 | 状态 |
|------|------|
| >15% | 黄 |
| >25% | 红（内部人宁可打折也要跑） |

### 3.3 云厂商应收账款周转（DSO）

账期突然拉长 → 供应商给客户放账续命。  
单独拉长 = 黄；叠加一级市场红灯 = 红。

### 3.4 其他旁证

- 未上市巨头加速 IPO 或折价私募
- 债务/表外融资激增为 capex 买单
- VC 对 AI 占比与 follow-on 意愿
